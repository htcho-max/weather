# 기상청 공식 데이터 연결하기 (약 20분)

하늘 앱은 기본적으로 Open-Meteo의 모델 예보를 써요. 아래 순서대로 중계 서버를 만들면
- 지금 기온·습도·바람·강수가 **기상청 관측값(초단기실황)**으로 바뀌고 (네이버 날씨와 같은 출처)
- 예보 모델 비교·성적표에 **‘기상청 공식’ 단기예보**가 더해져요.

인증키를 앱(index.html)에 넣으면 GitHub Pages에서 누구나 볼 수 있어서, 키는 중계 서버(Cloudflare Worker)에만 두고 앱은 서버 주소만 알게 했어요. 둘 다 무료예요.

## 1. 공공데이터포털 인증키 받기
1. https://www.data.go.kr 회원가입 후 로그인
2. 검색창에 **기상청_단기예보 조회서비스** → 오픈 API 상세 화면에서 **활용신청**
   - 활용 목적: 개인 날씨 앱 개발, 상세 기능은 모두 체크 → 신청하면 바로 자동 승인돼요
3. 마이페이지 → 데이터활용 → Open API → 활용신청 현황 → 방금 신청한 항목 → **일반 인증키(Decoding)** 복사
   - 발급 직후 1~2시간은 "등록되지 않은 키" 오류가 날 수 있어요. 기다리면 풀려요
   - 개발계정은 하루 10,000번까지 부를 수 있어요. 앱을 한 번 열 때 2번 써요

## 2. Cloudflare Worker 만들기
1. https://dash.cloudflare.com 가입(무료) 후 로그인
2. 왼쪽 메뉴 **Workers & Pages** → **Create** → **Create Worker**(Hello World 예제) → 이름을 `haneul-kma`로 → **Deploy**
3. **Edit code** → 원래 코드를 모두 지우고 이 폴더의 `kma-worker.js` 내용을 통째로 붙여넣기 → **Deploy**
4. Worker 화면 → **Settings** → **Variables and Secrets** → **Add**
   - Type **Secret**, 이름 `KMA_KEY`, 값: 1단계에서 복사한 인증키 → **Deploy**
   - (선택) Type **Text**, 이름 `ALLOWED_ORIGINS`, 값: 앱 주소. 예) `https://아이디.github.io`
     → 다른 사이트가 내 서버를 몰래 쓰지 못하게 막아요. 끝에 `/`나 경로는 붙이지 마세요
5. 확인: 브라우저에서 아래 주소를 열어 보세요 (`아이디` 부분은 내 Workers 주소)
   - `https://haneul-kma.아이디.workers.dev/` → `{"ok":true,...,"keySet":true}`
   - `https://haneul-kma.아이디.workers.dev/now?lat=37.5665&lon=126.978` → 서울 관측값
   - ALLOWED_ORIGINS를 넣었다면 주소창에서 바로 여는 건 되고, 다른 사이트에서 부를 때만 막혀요

> 명령줄을 쓰고 싶다면 이 폴더에서 `npx wrangler deploy` 후 `npx wrangler secret put KMA_KEY` (wrangler.toml 포함)

## 3. 앱에 연결하기
앱 맨 아래 **설정 → 기상청 공식 데이터**에 Worker 주소(`https://haneul-kma.아이디.workers.dev`)를 넣고
**연결 확인** → "연결됐어요. 서울 ○°" 가 나오면 **저장**.

- 해외 지역을 볼 때는 기상청 데이터를 부르지 않아요
- 기상청 서버가 안 될 때는 예전처럼 모델 값을 보여주고, 하늘 영역에 이유를 짧게 적어요
- 주소 칸을 비우고 저장하면 연결이 꺼져요

## 문제가 생기면
| 보이는 문구 | 해결 |
|---|---|
| 인증키가 등록되지 않았어요 | 발급 직후라면 1~2시간 기다리기. 계속되면 Decoding 키를 다시 복사해 KMA_KEY에 넣기 |
| Worker에 KMA_KEY(인증키)가 설정되지 않았어요 | 2-4단계에서 Secret 추가 후 Deploy 했는지 확인 |
| 허용되지 않은 사이트에서 온 요청이에요 | ALLOWED_ORIGINS 값이 앱 주소와 정확히 같은지 확인 (`https://아이디.github.io`) |
| 주소가 맞는지, Worker가 배포됐는지 확인해 주세요 | 주소 오타, 또는 Worker 코드를 Deploy 하지 않음 |
| 오늘 쓸 수 있는 요청 수를 다 썼어요 | 다음 날 자정에 풀려요 |
